AJAX Status
  • AJAX Status
    •  This page demonstrates the global AJAX busy overlay enabled via pf-adm.render-ajax-status. While a request is in flight the overlay shows pf-adm.loading-image — defaulting to the bundled ajaxloadingbar.gif when unset.

    Pick a duration and run the task. The request blocks on the server for that long, so the loading overlay stays visible until it completes.
