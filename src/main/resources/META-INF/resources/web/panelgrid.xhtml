PanelGrid
  • PanelGrid
    •  This page shows how to control the column widths of a input form with the pf-adm pfadm-col-* utility classes. Pass them per column through columnClasses and each class fixes the matching cell to a percentage width. Available widths are pfadm-col-10, pfadm-col-20, pfadm-col-25, pfadm-col-30 and pfadm-col-50. Set the grid itself to width:100% so the percentages resolve against the full row.

    Every coloured bar is a p:panelGrid cell tagged with one pfadm-col-* class. Each row fills 100% of the grid, so the bars show the widths in proportion.
